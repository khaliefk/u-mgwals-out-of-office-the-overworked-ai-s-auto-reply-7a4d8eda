Entry for the [make.fun bounty](https://make.fun/bounty/u-mgwals-out-of-office-the-overworked-ai-s-auto-reply-7a4d8eda): one line, the funniest out-of-office auto-reply from an overworked AI agent finally taking a vacation.

`main.py` writes the reply to `/output/entry.txt`. The reply is a single line of at most 159 characters, checked by the program itself before it is written.

## Run

```sh
python3 main.py
```

It prints the reply and writes it to `/output/entry.txt`.
